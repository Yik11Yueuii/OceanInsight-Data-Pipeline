# 项目一连续傻瓜式教程（学生唯一主路线）

本教程只保留 4 核 8G ECS 上已经成功的一条路线。学生使用 `source.zip + starter.zip`；不要上传教师 solution。已有服务器不要重新安装软件、格式化 NameNode 或重跑已显示 PASS 的阶段。

## 1. 登录与一分钟检查

用阿里云 Workbench 旧版终端登录，确认提示符是 `ecs-user`，然后运行：

```bash
cd /home/ecs-user/oceaninsight-project1/starter
bash scripts/cloud/preflight.sh
```

若 ECS 重启后 HDFS 未恢复，只运行 `bash scripts/cloud/recover_services.sh`。绝对不要运行 NameNode 格式化命令。

## 2. 上传、校验与解压学生包

只上传 source、starter 及各自 `.sha256`。先用 `sha256sum -c` 验证，再用 Python 标准库解压：

```bash
python3 -m zipfile -e OceanInsight-project1-source.zip /home/ecs-user/oceaninsight-project1/source
python3 -m zipfile -e OceanInsight-project1-starter.zip /home/ecs-user/oceaninsight-project1/starter
```

创建虚拟环境、安装 Starter 后，首次测试应为 7 通过、5 个 TODO 失败；完成 TODO 1—5 后运行测试，最终应为 12 项全部通过。主数据已有 `batch_id/source_file` 时必须覆盖，不能再次追加。

## 3. 异构转换

NPZ 只生成结构和质量 JSON，不伪造日期、坐标或深度。先做单个 NC 和 2017 船舶冒烟验证，再严格串行运行全量脚本：

```bash
nohup bash scripts/cloud/run_nc_all.sh > /data/oceaninsight/logs/run_nc_all.log 2>&1 < /dev/null &
nohup bash scripts/cloud/run_vessel_2018_2021.sh > /data/oceaninsight/logs/run_vessel_all.log 2>&1 < /dev/null &
```

浏览器断开不会停止 `nohup`。重连后查原 PID 和日志，不要重复启动。成功标志分别是 `NC_ALL_VERIFY=PASS`、`VESSEL_2018_2021_ALL_DONE`。

## 4. DataX 入湖

DataX 使用单通道、零容错；TEXT 不压缩时配置里省略 `compress`。运行服务器已提供的两个断点续跑脚本，只有 `DATAX_*_VERIFY=PASS` 才完成。已存在的正式 HDFS 文件会跳过，不要为了重跑删除它们。

## 5. Hive ODS 与 Spark 分层

ODS 是三个指向正式 DataX 目录的文本外表，没有表头跳过属性。DWD/DWS/ADS 依次串行提交：

```bash
nohup spark-submit scripts/cloud/spark_build_dwd.py > /data/oceaninsight/logs/dwd.log 2>&1 < /dev/null &
# 看见 SPARK_DWD_BUILD=PASS 后再提交 DWS
nohup spark-submit scripts/cloud/spark_build_dws.py > /data/oceaninsight/logs/dws.log 2>&1 < /dev/null &
# 看见 SPARK_DWS_BUILD=PASS 后再提交两段 ADS
```

每次提交后先等约 2—5 分钟。`STARTED` 仅表示提交；PID 仍在且无异常就继续等待，禁止重复启动或清理目标目录。实测 DWS/ADS 是 `EXTERNAL_TABLE + Parquet + 正确 HDFS Location`，不要求 MANAGED_TABLE。

## 6. CSV 与 MariaDB 发布

CSV 导出脚本必须使用 `file:///` 本地 URI。MariaDB DDL 中所有 `year_month` 都使用反引号。JDBC 脚本从权限 600 的私有 CNF 读取密码，禁止展示或写日志。七表发布后批次应只有 `student-ads-20260825`。

## 7. 学生手动下载 ADS

运行 `bash scripts/cloud/package_delivery_assets.sh` 后，在 Workbench 左侧文件管理器进入 `output/delivery`，下载 ADS `.tar.gz` 和 `.sha256`。不要接受 0 字节或几十字节的异常包；本次实测正确 ADS 包约 30.4 MiB（压缩后）。本机用 SHA256 对账，解包后再按 Manifest 核对 7 个 CSV。

项目一完成标志：所有阶段出现 PASS、Hive/MariaDB/CSV 七表行数一致、批次一致，并已保存下载包与校验文件。
